## Bug Fixes

- Bumped `h2` from 0.4.13 to 0.4.16 (hyper/reqwest instance) to fix `RUSTSEC-2026-0258` (unbounded empty DATA frames, low severity). The other instance, pulled in transitively via `actix-http` 3.13.1 (pinned to `h2 ^0.3`, no patched 0.3.x release exists), is now explicitly ignored in `deny.toml` with a note to revisit once actix-web migrates to h2 0.4.x. Also removed a stale `RUSTSEC-2023-0071` ignore entry that no longer matches any crate in the dependency tree.
- Regenerated the Nix `admin-ui` pnpm dependencies hash (`nix/expected-hashes/admin-ui.pnpm.*.sha256`) for all three platforms — it had gone stale after several Dependabot bumps to `admin-ui/pnpm-lock.yaml` (playwright, `@vitejs/plugin-react-swc`, tailwindcss, `@eslint/js`, globals) without a matching hash regeneration, breaking the Nix `Packaging` CI job.
- Fixed a flaky `admin-ui` unit test failure (`window is not defined`, `RealmContext.test.tsx`) two ways: guarded `RealmContext`'s `fetchRealms` against `setState` calls after the provider unmounts (it can still be in flight when a component unmounts mid-fetch, since it's also exposed as `refreshRealms` for manual re-fetch), and bumped the `setImmediate` scheduler-drain loop in the test setup's `afterEach` from 5 to 8 rounds, per the recipe already documented there for this exact class of React 19 + scheduler timing flake.
